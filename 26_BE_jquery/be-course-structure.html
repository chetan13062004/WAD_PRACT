PICT B.E. Course Structure

First Year (FE)

  • Engineering Mathematics I: Fundamentals of calculus and algebra
  • Engineering Physics: Basics of waves, optics, and quantum physics
  • Engineering Chemistry: Atomic structure, polymers, and corrosion
  • Programming in C: Introduction to programming and problem solving

Second Year (SE)

  • Data Structures: Linked lists, stacks, queues, and trees
  • Computer Organization: CPU, memory, and instruction cycle
  • OOP with Java: Classes, inheritance, and interfaces
  • Database Management Systems: SQL and relational databases

Third Year (TE)

  • Operating Systems: Process management, memory, and scheduling
  • Computer Networks: TCP/IP, routing, and network layers
  • Software Engineering: SDLC, Agile, and project management
  • Web Technologies: HTML, CSS, JavaScript basics

Final Year (BE)

  • Machine Learning: Supervised and unsupervised algorithms
  • Cloud Computing: Virtualization, AWS, and cloud models
  • Blockchain Technology: Distributed ledgers and smart contracts
  • Project Work: Final year team project with demo and report
